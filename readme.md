## ts 组件库


### 快速测试

```bash
cp .env.example .env
# 安装依赖
npm install

# 开发模式运行
npm run dev
npm run dev:test

# 构建
npm run build

# 生产模式运行
npm start
```

```text
http://localhost:3000/auth-test.html
```
